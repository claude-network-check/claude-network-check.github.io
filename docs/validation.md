## 页面交互与视觉

新版以总体结论和两个 Claude 访问出口为主信息：直接显示诊断端点 IP、对应地址的地区、运营商及 ASN；普通网页出口作为对照。IP 类型和信誉尚未接入可信数据源，明确展示未接入，不根据 ASN 名称推断住宅属性。

WebRTC、IPv6、DNS、ECS 与时区、语言、Intl、UTC 偏移直接可见。地区参考分降为辅助信息，不改变网络判断。按问题生成优先处理建议，分别链接具体证据与教程章节。全部 22 项证据默认折叠，原始检查能力保留。浏览器与 Claude Code 的检查范围分开说明。

使用 Ego Lite 检查桌面 1512、平板 768、手机 390 和 320 像素布局与截图。320 和 768 像素断网结果页无页面水平溢出，桌面模拟异常页亦无溢出；手机关键出口采用纵向布局。

浏览器验证：点击 Claude 出口自动打开完整证据和对应详情；未确认筛选仅呈现未知项；搜索 WebGL 自动展开设备组；Enter 可展开原生详情。仅浏览器检查会清除上次网络结果，显示 12/22 项与“网络尚未验证”，避免混用旧数据。初始态没有跨站探测请求。

模拟结果覆盖出口差异、DNS ECS、IPv6 失败、WebRTC 不可用、全部网络请求失败和用户停止。全断网时十项网络结果均未知；停止后没有残留加载状态。脱敏导出包含各项检查及评分说明。模拟使用保留测试地址，不证明实际线路质量。

新增回归测试验证总体结论、未知与本地检查范围、具体修复入口，以及两个 Claude 端点归属不能借用普通网页出口信息。原有 IP/ICE/DNS、取消、限流和脱敏测试继续通过。

## 限制

验收不修改系统网络，不执行真实 Claude 付费调用。免费 IP 归属服务是当前主要瓶颈。对照范围仅为 IPPure 的 Claude 页面，详见[逐项清单](coverage.zh-CN.md)；不同外部服务返回的样本数和归属库可能不同。

## v0.4.1 真实接口复测

修复前，10 项网络检查中有 5 项未确认。根因包括 ipwho.is 限流、未取得 IPv6 连带否定 IPv4 出口对照，以及 WebRTC 无公网候选被统一归为未确认。

接入 country.is 国家查询、ipapi.is 匿名基础归属、ipwho.is 元数据备用，以及 ident.me 地址回显备用后，本次真实浏览器得到 7 项网络观测、1 项 ECS 待核对、2 项检测受限。两个 Claude 出口均取得地区及运营商，DNS 取得归属，已取得 IPv4 样本内出口一致。

两个受限项为：ipify 与 ident.me 的 IPv6-only 请求均未连通；WebRTC 本次没有采集到公网候选。页面明确展示范围，未将其作为无泄露证明。没有把限流隐藏为成功，也没有用其他网站的出口代替 Claude 出口。

新增 6 项测试覆盖国家信息降级、匿名元数据结构、缓存、地址服务切换、取消不再调用备用服务、IPv6 可选对照及受限结论。公开截图仍只保存初始态。
