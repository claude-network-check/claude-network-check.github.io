## 为什么旧版结果和 IPPure 不一样

2026-10-24 用同一台机器、同一个浏览器对比，旧版与 IPPure 的差异来自三处：

1. **评分算法不同。** 旧版只用四项（时区 40、语言 30、Intl 20、UTC+8 10），不计字体和系统风格，UTC+8 记满分。IPPure 用六项加权并给部分分。同一环境旧版 10 分、IPPure 28 分。新版改用相同算法，现在两边都是 28 分。
2. **DNS 样本太少。** 旧版只查 3 次 Upset EDNS，常常只看到 1–3 个解析器，还把正常的 ECS 子网当作“需核对”。新版与 IPPure 一样用四个服务查 16 次，只把中国大陆解析器判为泄露。
3. **WebRTC 只连 Cloudflare STUN。** 分流规则下国内流量直连时，旧版看不到泄露。新版同时连接 B 站、小米、芒果 TV 的 STUN。

net.coffee 的 IP 评分与“中国出口”数据来自其自有后端，本项目无法复现，只用公开免费服务实现了 IP 类型与匿名标记。

## 仍会有的差异

- DNS 与 WebRTC 每次采样到的解析器、候选地址不同，数量会有浮动。
- 不同 IP 库对同一地址的城市、运营商、机房 / 住宅判断可能不一致。
- 出口地区优先采用 Claude 前端 Cloudflare 自己返回的国家代码，这是 Claude 真正看到的结果，可能与第三方 IP 库不同。
