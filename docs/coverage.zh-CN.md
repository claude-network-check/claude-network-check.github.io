# IPPure Claude 页面对照

核对时间：2026-10-17。参照 [IPPure Claude 页面](https://ippure.com/claude) 当时实际加载后的界面；仅比较这个页面的检测能力，不包含其其他工具页。没有复制它的源码或 UI，也不保证相同分数。

## 已覆盖的核心检测

| 参考页面的检测 | 本项目实现 | 限制 |
| --- | --- | --- |
| claude.ai 出口 | 独立请求 trace，显示 IP 并查询该地址的地区、运营商和 ASN | 不是账号或 API 可用性检测 |
| claude.com 出口 | 独立请求 trace，显示 IP 并查询该地址的地区、运营商和 ASN | CORS/网络失败保留未知 |
| WebRTC 地址与地区 | ICE 公网、本地、mDNS 分类；公网候选最多查询三个地址的地区，并比较 HTTP 出口 | 没有候选不判安全；归属服务失败会说明 |
| DNS 解析器与地区 | 三个随机域名观测样本，解析器去重及国家/运营商查询 | 不同服务的节点覆盖不同，样本不代表全部 DNS 路径 |
| 系统时区 | IANA 时区标识 | 只代表浏览器可见值 |
| 浏览器语言 | 首选与完整 navigator.languages，提示非首选中文 | 语言偏好不证明地区 |
| 中文字体 | 24 种中文字体、两段文字、三组回退字体的 Canvas 字宽比较 | 回退、别名和隐私保护会误导推断 |
| Intl 区域设置 | 日期、数字 locale、日历、数字系统与格式样例 | 不能等同用户国籍 |
| UTC 偏移 | 当前值与 1 月/7 月季节偏移 | UTC+8 被多个国家和地区使用 |
| Emoji 风格 | UA 平台风格推断，并增加四个 Emoji 的实际彩色像素观测 | 参考页当前面板说明为 UA 推断；不将单色认定为地区屏蔽 |

## 新增的独立检查

1. 公网 IPv4 回显。
2. 公网 IPv6-only 回显。
3. IP 归属、ASN、运营商与归属时区。
4. 多域名出口一致性：按 IPv4 / IPv6 分组，避免跨协议误判。
5. DNS ECS 子网观测。
6. HTTP 响应稳定性：三次请求的成功数、中位总耗时、耗时差值和出口变化。
7. 首选语言与 Intl 主语言的一致性。
8. IANA 时区与 Date 当前 UTC 偏移的一致性。
9. 浏览器与系统：UA、Client Hints、平台、移动提示、webdriver。
10. WebGL 厂商和渲染器，含被隐藏时的通用值。
11. 屏幕分辨率、可用区域、DPR、色深、触控与指针。
12. 安全上下文、Cookie 开关、DNT、GPC 与 WebRTC API 可用性。

共 22 个检测项：10 项网络观测、12 项本地检查。数量按独立观测项计，不把每个返回字段都算一个检测，也不把工具网站的其他页面当作对照范围。

## 评分与覆盖不是同一件事

本项目沿用已公开的四项简单参考指数：时区 40、首选语言 30、Intl 20、UTC+8 10。字体和 Emoji 均有实际检测，但由于地区解释很弱，不强行加入分数。新增的网络与设备检查也不自动改写该指数。

因此“覆盖更多检测”不代表概率更准。没有 Claude 内部标签或经过校准的数据，不能计算真实识别概率。也不会复述未经独立核实的遥测、账号封禁或隐写机制推测。

## 外部依赖

全面检测最多发起 3 组 IPv4、1 组 IPv6 地址探测（ipify 失败后切 ident.me，每组最多两个服务）、2 次 Claude trace、3 次 Upset DNS 请求（包含服务重定向）、1 个 STUN 会话，以及 8 个去重 IP 的归属查询（每地址最多三个服务）。国家和元数据独立查询，结果只在内存缓存 5 分钟；缺失信息不会被编造为成功。

浏览器本地检查不发送跨站请求，不生成指纹哈希、不请求设备权限、不写入存储。网络检测依赖免费服务的实时可用性，不承诺比参考页面在每个地区都能取得更多有效样本。
