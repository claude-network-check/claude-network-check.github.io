          常见问题

          为什么和其他检测站的结果不一样？

          DNS 和 WebRTC 每次采样的解析器、STUN 服务器不同，出口 IP 的归属数据库也不同。本页的中文环境评分与 IPPure 使用相同的权重和分段，同一浏览器下分数应当一致；出口地区优先采用 Claude 前端 Cloudflare 自己返回的国家代码，而不是第三方 IP 库。

          DNS 泄露和 WebRTC 泄露有什么区别？

          DNS 泄露是系统把域名交给国内解析器，访问记录被看到；WebRTC 泄露是浏览器通过 UDP 绕过代理，直接暴露真实 IP。前者用代理客户端的 DNS 接管解决，后者用 TUN 模式或浏览器的 WebRTC 策略解决。见配置教程。

          中文环境分数低就代表账号安全吗？

          不代表。分数只反映浏览器能读到的区域信号。IP 信誉、支付方式、使用行为同样会影响风控，这些网页无法检测。

          浏览器结果能代表 Claude Code 吗？

          不能。终端、编辑器和浏览器可能走不同的代理。终端请确认 TUN 已接管或环境变量已设置，并检查系统时区。可用诊断 Skill 协助核对。

          数据与隐私

          打开页面即开始检测。浏览器会直接连接：claude.ai 与 claude.com 的 trace 端点、icanhazip / ipify / ident.me（出口 IP）、ipinfo.io / ipwho.is / country.is（IP 归属）、ipquery.io（IP 类型）、Surfshark / Fastly / BrowserLeaks（DNS 泄露）以及 5 个公共 STUN 服务器。这些服务能看到你的出口 IP。

          本页没有后端、没有统计脚本，检测结果只在当前页面内存中，复制的报告默认隐藏 IP。免费服务可能限流或失败，失败项显示为「未知」，不会当作通过。
